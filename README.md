# ZaZise static preview (GitHub Pages)

**Preview:** https://truthcornersa.github.io/zazise-preview/  
**Live Afrihost site (untouched):** https://www.zazise.africa/

## Self-contained

This preview ships its own `styles.css`, `home.css`, `home-menu.css`, `docs-page.css`, `js/`, and `assets/`.
It does **not** load CSS/JS/images from www.zazise.africa (no Afrihost dependency for static assets).

PHP `/api/*` does not run here — register/login are UI-only.

## Pages setup

Source: **Deploy from a branch** → **main** → **/ (root)**.
