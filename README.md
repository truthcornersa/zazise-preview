# ZaZise static preview (GitHub Pages)

Static HTML/CSS/JS preview of the ZaZise UI wireframes for design review.

- **Live Afrihost site:** https://www.zazise.africa (separate — not this repo)
- **Preview URL:** https://truthcornersa.github.io/zazise-preview/

## Notes

- PHP APIs (`/api/*`) do **not** run on GitHub Pages. Registration/login submits are UI-only here.
- No secrets, user databases, mail drafts, or deploy scripts are included.
